# Boids Simulation with Predator

## Краткое описание

**Boids Simulation with Predator** — это интерактивная симуляция стайного поведения (алгоритм Boids) на Java с графическим интерфейсом Swing. Рыбки (boids) следуют трём классическим правилам: сепарация (избегание соседей), выравнивание (синхронизация скорости) и когезия (стремление к центру группы). Добавлен хищник, который преследует стаю, а также система авто‑респавна для поддержания популяции.

Проект реализует многопоточность на уровне каждой сущности, паттерн **MVC**, возможность сохранения и загрузки состояния симуляции, анимационные эффекты (машущий хвост, блики, тени) и удобное меню. Идеально подходит для изучения искусственной жизни, параллельного программирования и компьютерной графики.

## Функции

- **Стая рыбок** – до 100+ агентов, управляемых правилами Boids:
  - *Сепарация* (радиус 15 px) – избегание столкновений.
  - *Выравнивание* (радиус 60 px) – синхронизация направления.
  - *Когезия* (радиус 100 px) – притяжение к соседям.
- **Хищник** – движется быстрее рыбок (3.8 px/шаг против 2.5), преследует ближайшую цель.
- **Паника** – при приближении хищника (радиус 110 px) рыбки разбегаются.
- **Поедание** – хищник съедает рыбу при касании (радиус 12 px), остаётся временный эффект вспышки.
- **Респавн** – если количество рыбок падает ниже 20, автоматически добавляется 5 новых в случайные места поля.
- **Сохранение и загрузка** – состояние симуляции (позиции, скорости, флаги) сохраняется в файл `.sav` и загружается обратно.
- **Многопоточность** – каждый агент работает в своём потоке, синхронизация через неизменяемые снимки и потокобезопасные коллекции.
- **Меню и управление**:
  - Главное меню: новая игра, загрузка, выход.
  - Меню паузы: продолжить, сохранить, в главное меню.
  - Клавиши: **Space** – пауза/продолжение, **Esc** – выход в главное меню.
- **Визуализация**:
  - Градиентные тела рыбок, анимированный хвост.
  - Реалистичный вид хищника (акула с зубами).
  - Тени, блики воды, эффект поедания.
  - Отображение количества рыб в стае и подсказки по управлению.

## Установка и запуск

### Требования
- **Java 11** или выше
- Любая IDE (IntelliJ IDEA, Eclipse) или компилятор из командной строки

### Клонирование и сборка
```bash
git clone https://github.com/Sovynhik/boids-simulation-with-predator.git
cd boids-simulation-with-predator
javac -d bin $(find src -name "*.java")
# или используйте сборку в вашей IDE
```

### Запуск
```bash
java -cp bin ru.rsreu.savushkin.boidssimulation.ClientRunner
```

После запуска откроется окно симуляции.  
- Нажмите **"Новая игра"** в главном меню.  
- Управление: **Space** – пауза, **Esc** – выход в меню.  
- В меню паузы доступны сохранение и возврат в главное меню.

## Архитектура

Проект следует паттерну **Model‑View‑Controller**:

- **Model** – `SimulationModel`, `Entity` (абстрактный класс), `FishEntity`, `PredatorEntity`.  
  Отвечает за логику поведения, коллизии, респавн, состояние симуляции.  
  Хранит коллекции сущностей в потокобезопасных `CopyOnWriteArrayList`.

- **View** – `SimulationView` (главный контейнер Swing), `Renderer`, `MenuManager`, `InputManager`.  
  Отвечает за отображение, анимацию, обработку ввода.

- **Controller** – `SimulationController`.  
  Передаёт команды от представления к модели и обеспечивает доступ к состоянию.

- **DTO (Data Transfer Objects)** – `SimulationState`, `EntityDTO` – для сохранения/загрузки состояния.

- **Многопоточность**:  
  - Каждая сущность (рыбка, хищник) запускается в отдельном потоке через `ExecutorService`.  
  - Потоки сущностей получают актуальный снимок (`SimulationSnapshot`) через `AtomicReference` и пересчитывают своё поведение.  
  - EDT (Event Dispatch Thread) обрабатывает таймер обновления, который вызывает `update()` модели и последующую перерисовку.

- **Синхронизация**:
  - `volatile` флаги `simulationOver`, `paused`.
  - `AtomicReference` для снимка.
  - `CopyOnWriteArrayList` для списков сущностей и эффектов.
  - `Collections.synchronizedSet` для подписчиков.

## Детали реализации

### Правила Boids
- **Сепарация** – сила, направленная от соседей в радиусе `SEPARATION_RADIUS` (вес 2.2).
- **Выравнивание** – усреднение скоростей соседей в радиусе `ALIGNMENT_RADIUS` (вес 1.2).
- **Когезия** – сила к центру масс соседей в радиусе `COHESION_RADIUS` (вес 0.35).
- **Паника** – если хищник ближе `PANIC_RADIUS`, рыбка убегает от него с увеличенной силой.
- **Jitter** – небольшая случайная составляющая для естественности (вес 0.8).

### Многопоточность и синхронизация
- Каждая сущность работает в своём потоке, получая через `model.getCurrentSnapshot()` неизменяемый снимок состояния на момент начала итерации.
- Снимок содержит копии всех позиций и скоростей, что гарантирует отсутствие гонок при чтении.
- Изменения (удаление рыб, добавление новых) производятся только в EDT (в методе `update()` модели), поэтому потоки сущностей никогда не модифицируют общие коллекции напрямую.

### Сохранение / загрузка
- Используется стандартная сериализация Java.
- Сохраняются: позиции, скорости, идентификаторы всех рыб и хищника, флаг `simulationOver`.
- При загрузке все старые потоки останавливаются, создаётся новый пул и восстанавливаются сущности с сохранёнными параметрами.

### Визуальные эффекты
- Анимированный фон (сдвигающиеся волны).
- Тени под объектами.
- У каждой рыбки – машущий хвост, синхронизированный по времени и уникальному ID.
- Хищник нарисован в виде акулы: спинной плавник, зубы, злые глаза.
- При поедании появляется расходящаяся окружность.
